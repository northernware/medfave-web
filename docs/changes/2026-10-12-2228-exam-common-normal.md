# Exam: "Common systems normal", shorter "More systems"

Opened: 2026-10-12 22:28 PHT

## What
- "Common systems normal" above the exam sets each common system (general survey, HEENT, lungs, cardiovascular, abdomen) that isn't examined yet to its normal. Systems already recorded aren't touched. The button goes once none are left.
- "More systems" shows just the count, not all eleven names.

## Why
UI pass: a routine visit took five Normal clicks, and the long button text wrapped and repeated the list it opens. The app gets the same changes.
