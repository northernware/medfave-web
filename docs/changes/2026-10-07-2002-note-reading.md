# A note reads the same everywhere: whole in the panel, the edit page's layout as a page

Opened: 2026-10-07 20:02 PHT

## What
- **Side panel** (a note opened from the visit history or Today) shows the whole note and no longer repeats the patient's allergies and alerts (the chart's, on the clipboard behind it, not the note's). Buttons: Amend / Continue note, Print prescription (author, when there are prescriptions), and a "History and full page" link.
- **Full note page** takes the edit page's layout: the note on the left, the patient clipboard beside it (`NoteLayout` + `NoteContext`), centred like the edit page. The header says when, age at the visit and the author; the clipboard names the patient. The allergy boxes in the main column are gone.
- **"Last visit" beside an existing note** is the one before that note (`NoteContext` `before`), not the latest; reading a July note no longer shows September as its last visit.
- **Change notes from today** renamed and rewritten to the format in `AGENTS.md` (time-stamped names, What / Why / Tested sections).

## Why
Owner: the visit history opened half a note, repeated allergies and alerts, and "Open full note" was a third, different layout; only the amend page looked right.

## Tested
`tsc`, eslint. Headless Chrome: Corazon's July note in the side panel (whole note, Amend / Print / History link) and as a full page (note left, clipboard right; "First visit with you" since it is her earliest).
