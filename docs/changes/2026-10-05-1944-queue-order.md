# Doctor API: queue with the doctor first, then by arrival

Opened: 2026-10-05 19:44 PHT

## What
- `GET /doctor/day` → `queue`: whoever is in consultation comes first, then the checked-in in arrival order (longest wait first). Before, both were mixed in one arrival order, so someone with the doctor could sit between two waiting patients.
- `docs/api.md` updated.

## Why
The owner found the app's waiting room order unclear. It matches the web's split lists and the patient's "ahead of you" count, which is unchanged.
