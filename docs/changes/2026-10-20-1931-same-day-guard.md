# Booking: one open visit per patient per day

Opened: 2026-10-20 19:31 PHT

## What
- `bookAppointment` (web form and app alike) refuses a booking when the patient already has an open visit (pending, confirmed, checked in, in consultation) with that doctor on that clinic day. The API answers `409 { error, existing }`; `allowSecond: true` books anyway. The web form shows a "Book another visit that day anyway" checkbox when it happens.
- `docs/api.md` updated.
