# Coded diagnoses on visit notes (WHO ICD-11)

Opened: 2026-10-06 15:02 PHT · Updated: 2026-10-06 15:06 PHT

## What
- **Diagnoses (ICD-11)** on the visit note form: search by code ("CA23") or words ("asthma"), pick one or more; the first is primary ("Make primary" reorders). Assessment stays free text for the reasoning.
- Shown on the note page, in the patient's visit list (instead of the assessment line when present), and in the API.
- **Data:** `Icd11Code` (the WHO MMS list) and `VisitDiagnosis` (code, title, URI and position, copied per note). Migration `20261006T0656_icd11_diagnoses`, additive only.
- **List:** `npm run icd11:import [release]` downloads WHO's release file (default 2026-01) and loads about 35,700 codes. The list isn't kept in this repo.
- **Saving:** the form sends codes in order; the server looks titles and URIs up, so stored text is exactly WHO's. Diagnoses join the version snapshot, so an amendment that changes them shows in the history. A save that doesn't carry `dx.present` (the current app) leaves a note's diagnoses alone.
- **API:**
  - `GET /doctor/diagnoses?q=` (search);
  - `POST /doctor/records` takes `diagnoses: [code]`;
  - `record.diagnoses` and `visits[].diagnoses` are returned.
- **Search:** a code prefix, or words that each start a word of the title. Chapters X (extension codes) and 26 (traditional medicine) are left out. Our own aids sit on top of WHO's list without changing it: a short list of common family-practice diagnoses ranks first among equal matches (hypertension → BA00), and a few everyday terms point to codes ("high blood pressure", "htn", "uti", "lbm", "ptb"…).
- Tests: `lib/diagnosis-rank.test.ts` (search ordering, common diagnoses, synonyms).

## Why
A doctor asked for diagnoses based on ICD codes. The owner chose ICD-11 over ICD-10: WHO licenses ICD-11 for commercial use under CC BY-ND 3.0 IGO, while ICD-10 in a commercial product needs a WHO licence. The DOH issued ICD-11 implementation guidelines (AO 2025-0021, October 2025).

## Tested
- `tsc` (apart from the missing `@solar-icons/react` install), eslint, `npm test` (18).
- Migration applied to the shared dev DB; `migrations/app/refs/db.json` moved to `1c31c0df…`. `icd11:import` loaded 35,664 codes in about 9 s.
- Against the local server: search "asthma" → CA23 Asthma first; "hypertension" / "high blood pressure" / "htn" → BA00; "uti" → GC08 with no stray matches. A draft note saved with BA00.Z and CA23.32 returns both with WHO's titles and URIs. A save without `diagnoses` keeps them, reordering and removing work, and an unknown or extension code gets a 422.
- **Not seen in a browser:** the picker on the note form and the diagnoses on the note and patient pages.
