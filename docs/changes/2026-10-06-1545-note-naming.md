# Visit notes: one set of words; "Write note" 404 fixed; normal ids for demo rows

Opened: 2026-10-06 15:45 PHT

## What
- **404 fixed:** since the side panel (#154), a soft link to `/records/new` was caught as a note called "new" and showed "Nothing here". `@modal/(.)records/new` now reloads it as the full page (`components/full-page.tsx`).
- **Wording.** One noun, "visit note", and four verbs:
  - **Write note** (was "Document visit", "Write notes");
  - **Open note** (was "View record", "Open notes");
  - **Continue note** (was "Continue writing");
  - **Amend note** (was "Amend record").
  - Page titles: **New visit note**, **Visit note**, **Visit note (draft)**, **Amend note** (were "Document visit", "Medical record", "Consultation notes", "Edit record", "Amend record"). Archive and restore say "note" too.
- **Demo ids:** the showcase and scenario seeds no longer make readable ids like `drshow-today-waiting`. They use normal-looking ids starting with a fixed marker (`src/prisma/seed-ids.ts`: `d0c70000-…` doctor, `5a7e0000-…` patient, `5ce00000-…` scenarios), so a rerun still finds its own rows. Old readable rows are cleared on the next run.

## Why
Owner: a visit URL read `drshow-today-waiting`, "Document visit" went to a 404, and notes had four names.
