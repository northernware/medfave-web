# Week API: count every visit, for the calendar's dots

Opened: 2026-10-19 13:01 PHT

## What
`GET /api/v1/doctor/week` takes `count=any`: per day, every visit that isn't cancelled, past ones included. By default it still counts only visits still expected (Today's day strip).

## Why
The app's month calendar marks days with visits, past days included.

## Tested
`tsc` and `eslint` pass. On the local dev server, for October with `count=any`, past days have counts too, where the default only counts days still ahead.
